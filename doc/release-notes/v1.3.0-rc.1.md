# Resin v1.3.0-rc.1

> [!NOTE]
> This is a release candidate. The per-IP account quota feature set is complete and covered by tests, but it has only been validated on a small single-node deployment. Production feedback is welcome; a stable v1.3.0 follows after burn-in.

## Per-IP Account Quota

- Cap the number of distinct accounts routed through each egress IP within a rolling window, mitigating IP-farm risk flags triggered when too many accounts share one IP.
- Configurable per platform: `max_accounts_per_ip` (0 disables, the default) and `ip_account_window` (Go duration, defaults to 2h).
- Window slots follow recent-activity semantics: an entry slides out one full window after the account's last activity, so an actively used account keeps its slot while an account idle for the whole window releases it (no more ghost slots from first-seen bookkeeping).
- Lease hits and same-IP rotation refresh the window entry, so a live lease always occupies a slot; when an IP reaches the fail-open ceiling, its existing lease is invalidated and re-routed instead of silently over-exposing the IP.
- Sticky leases are unaffected: quota is enforced only when a new account-IP lease would be created.
- When every live IP is at capacity, one fallback slot per IP (`max + 1`) keeps requests flowing (fail-open); beyond that, requests fail closed until window slots slide free.
- Control-plane-created leases consume quota as well; window state survives restarts (seeded from persisted leases, keyed by last access) and expired entries are pruned by the lease cleaner.
- Monitor live usage via `GET /api/v1/platforms/{id}/ip-quota` or the WebUI platform monitor tab. The API now returns per-account detail (account, last seen, fail-open flag, lease presence) for every in-window IP.
- Structured log events and `ip_quota_blocked_total` / `ip_quota_fallback_total` counters for observability.
- Design document: [2026-08-15-resin-ip-account-quota-design.md](https://github.com/gmcheck/Resin/blob/master/2026-08-15-resin-ip-account-quota-design.md).

## WebUI

- Platform quota form fields now carry an inline advisory explaining the quota algorithm and the flag-2 risk line (5 distinct accounts per IP within 10 minutes), including the recommended `3 accounts / 2h` setting that stays safely below it.
- New IP quota panel in the platform monitor tab: per-IP window account counts with utilization bars, blocked/fallback counters, and a guidance empty state when quota is disabled.
- Clicking an egress IP opens a per-IP account modal listing every in-window account with status badges (in-use lease, residual window entry, fail-open slot) and last-activity time; it auto-refreshes every 5s.
- The modal and the lease management table are cross-linked: an in-use account links straight into lease management with the account search pre-filled, and an egress IP in the lease table jumps back to the monitor tab and opens that IP's account modal.
- Platform detail overview shows an "IP quota" fact (e.g. `3 accounts/IP · 2h` or `Disabled`).

## Proxy Error Classification (Windows)

- Windows Winsock errnos (`WSAECONNRESET` and friends) are normalized to unified errno names, so benign client-side resets after a completed response are correctly exempted from tunnel failures, and upstream telemetry reports `connection_reset` instead of `ERRNO_10054`.

## Upgrade Notes

> [!IMPORTANT]
> Persisted legacy Platform regex filters are automatically migrated to composable tag-filter rules during startup. This database migration is irreversible because earlier releases cannot represent OR or exclusion rules.

- Back up `<RESIN_STATE_DIR>/state.db` before upgrading.
- To downgrade to an earlier release, stop Resin and restore the pre-upgrade backup. Do not attempt to roll back the migrated database.
- New additive migration `000010_platforms_add_ip_account_quota` adds `max_accounts_per_ip` and `ip_account_window_ns` columns; defaults keep quota disabled, so upgrading alone changes no routing behavior.
- Docker: RC images are published as `1.3.0-rc.1` (and `1.3`); the `latest` tag keeps pointing at the last stable release.
