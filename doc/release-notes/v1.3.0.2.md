# Resin v1.3.0.2

> [!NOTE]
> This is a stable maintenance release on the v1.3 line. Going forward the project ships formal patch versions only (v1.3.0.1 → v1.3.0.2 → …); no more `-rc` suffixes are used.

## Per-Subscription User-Agent

- Subscriptions can now declare a custom `User-Agent` used when fetching their content. Some providers serve drastically different payloads per client UA (observed in the wild: `clash.meta` received a 10-node VLESS+WS subset while `clash-verge/v2.5.2` received the full 44-node VLESS+Reality list). Leaving the field empty keeps the default `clash.meta`.
- Configurable per subscription via the WebUI (create dialog and edit drawer, remote sources only) and via the API: `user_agent` on `POST /api/v1/subscriptions` and `PATCH /api/v1/subscriptions/{id}`. Clearing the value restores the default.
- Changing a subscription's User-Agent automatically triggers a refresh, mirroring the existing behavior for URL changes.
- The value is persisted and survives restarts; download retry paths honor it as well.
- Additive migration `000011_subscriptions_add_user_agent` adds the column with an empty default, so upgrading alone changes no fetch behavior.
- Implementation notes: the downloader gained an optional `DownloadWithUserAgent` capability used by the subscription scheduler; unrelated downloaders (GeoIP) keep the shared default UA. The scheduler's fetcher signature now carries the per-subscription UA, and per-attempt snapshots include it so in-flight refreshes stay consistent with the config version they started from.

## WebUI Fixes

- IP quota account modal: long account names (e.g. `sso_<32-hex>`) no longer push the "Lease" quick-action button out of view. The account name truncates with an ellipsis (full value on hover) while the button remains visible and clickable at any length.

## Upgrade Notes

- Back up `<RESIN_STATE_DIR>/state.db` before upgrading, as with any release.
- The new migration is purely additive (new column, empty default). Existing subscriptions keep using the default `clash.meta` UA until configured otherwise.
- Docker image: `ghcr.io/gmcheck/resin:1.3.0.2`.
- Reality-protocol nodes require uTLS, which the published Docker images have always included (`-tags with_utls`). If you build from source, use `go build -tags "with_quic with_wireguard with_grpc with_utls" ./cmd/resin`; plain `go run ./cmd/resin` without tags cannot dial VLESS+Reality outbounds.
